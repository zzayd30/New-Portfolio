# Zaid — Portfolio 2026

Personal portfolio for Muhammad Zaid Latif, built with Next.js, TypeScript, Tailwind CSS, and Motion.

## Getting started

```bash
npm install
cp .env.example .env.local
npm run dev
```

Update `.env.local` with the Gmail SMTP app password used by the server-side contact form.

## Checks

```bash
npm run typecheck
npm run lint
npm run build
```
